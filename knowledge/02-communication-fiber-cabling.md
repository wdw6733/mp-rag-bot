# 通信工程：光纤与综合布线

## 是干什么的

综合布线是把建筑物里的网线、光纤、配线架、信息点按规范布好，让所有终端都能连上网络。光纤负责长距离、大带宽的传输，网线负责房间里短距离的接入。机房到楼层、楼层到房间，靠的就是这两样东西。

光纤用光传信号，抗电磁干扰，距离远、带宽大，是楼宇之间、机房之间、运营商骨干的首选。网线用铜传电信号，便宜、好接，适合百米以内的接入。

## 怎么工作

### 光纤分单模和多模

单模光纤芯径很细，只走一条光路，距离远，用于千米级以上的链路，常见黄色外皮。多模光纤芯径粗，光路多，距离短，用于机房内部几百米，常见橙色或水绿色外皮。两者不能混用，接头和光模块要配套。

光纤链路两端是光模块，插在交换机上。光模块有速率和波长之分，链路两端速率、波长、光纤类型要一致，否则链路起不来或误码很高。

### 熔接与冷接

光纤接续有两种做法。熔接是用熔接机把两根光纤端面熔在一起，损耗小、稳定性好，是工程里的主流做法。冷接是用机械接续子对准固定，速度快但损耗稍大、长期稳定性差一点，适合临时抢修。

熔接前要剥除涂覆层、清洁端面、切割平整；完成后套热缩管保护，盘进熔接盒，别让光纤弯得太厉害。

### 综合布线分系统

按位置分：工作区子系统是房间里的信息点和跳线；水平子系统是楼层配线架到信息点的网线；垂直子系统是楼层之间的主干，一般是光纤；管理子系统是配线架、理线架；设备间子系统是机房里的配线和设备。

每根线两端都要贴编号，配线架、信息面板、跳线一一对应；没标签的布线，查故障只能一根根拔着试。

测一条光纤链路通不通、损耗大不大，用光功率计和光源，或者 OTDR：

查交换机上光模块的状态（以常见交换机命令行举例，实际命令以设备手册为准）：

```bash
display transceiver interface GigabitEthernet0/0/1
```

看输出里的收发光功率、温度、电压是否在正常范围。收光功率过低，先查光纤接头脏不脏、熔接点损耗大不大，再查对端发光是否正常。


## 常见坑

- **光纤弯折半径太小**：光纤不能像网线那样随便弯，弯太急光会漏出去，损耗变大。盘纤时弯曲半径至少是光纤直径的 20 倍，余长自然盘，不要硬塞。
- **光纤接头脏了**：灰尘是最常见的光纤故障。拔插前用清洁笔或无尘纸清洁，别用手摸端面，别对着接头吹气。
- **单模多模混用**：单模光模块插在多模光纤上，链路可能时通时断；反过来也一样。布线前先确认光纤类型，再买对应的光模块。
- **网线超长**：网线有效距离是 100 米（含跳线），超了信号衰减严重，速率会掉到百兆甚至断断续续，超长要改走光纤。
- **标签缺失**：布线时省了贴标签的功夫，查故障要花十倍时间补。线一布好就贴标签，三处编号一致。
- **强电弱电同槽**：网线和强电线同槽会受干扰，误码率上升。分开走，平行间距至少 30 厘米，交叉处垂直。
